# UI languages

Orbit supports `ko` and `en`. Choose a language in Settings → Appearance, or on the sign-in screen. The `orbit-ui-locale` cookie supplies the first server render; local storage synchronizes open tabs. Browser language is used when no preference exists.

Use `useI18n()` for `t(source, values)`, `errorText(error)`, `locale`, and `intlLocale`. Catalogs live in `src/lib/i18n/en.json` and `ko.json`. Interpolate values as `{0}`, `{1}`, etc.; keep every argument in each translation.

Translate system labels only. Preserve note bodies, titles, folder names, mail content, and renamed categories. Use `Intl` with `intlLocale` for display; keep stored dates and times unchanged. Reserved category IDs use translated built-in names until renamed.

Keep effects that load or save data independent of language. Store their source error/status text and translate when rendering. Language changes flush pending embedded-canvas writes before reconfiguring note-editor menus.

`pnpm test:unit` checks explicit UI-message coverage, catalog placeholders, locale selection, interpolation, errors, date labels, and pending-write handling.
